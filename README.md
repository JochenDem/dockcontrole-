# dockcontrole

Pagina om de klaargezette routes aan het dok af te vinken.

- De routes komen uit de tabel `dock_routes` in het Supabase-project **work-sap**.
- Klaarzetten gebeurt vanuit de Dockcontrole-pagina (knop **Naar controle sturen**), met de TU als sleutel.
- Inloggen met dezelfde work-sap-login als de andere pagina's.
- Wat je afvinkt (6m, 6.5m, stillage type, paletten, dozen en de crossdockgegevens) wordt automatisch teruggeschreven.
- **Controle afgerond** zet de route op afgewerkt, met tijdstip en e-mailadres.

Eén bestand, `index.html`, zonder bibliotheken. Zet GitHub Pages aan op de branch `main`, map `/ (root)`.
